# NeRF Turntable — 2D Photos to 3D Neural Rendering

A PyTorch implementation of **Neural Radiance Fields (NeRF)** that turns a set of circular turntable photos into a continuous volumetric 3D representation capable of synthesizing novel, unseen 360° views. Includes a full-stack web application (FastAPI + React) for one-click animation generation.

## What is a NeRF?

A **Neural Radiance Field (NeRF)** represents a 3D scene not as a polygonal mesh or point cloud, but as a continuous function parameterized by a deep neural network (MLP). The network maps a 5D coordinate—spatial location $\mathbf{x} = (x, y, z)$ and viewing direction $\mathbf{d} = (\theta, \phi)$—to an emitted color $\mathbf{c} = (r, g, b)$ and volume density $\sigma$:

$$F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\mathbf{c}, \sigma)$$

To synthesize an image from a novel viewpoint:
1. **Ray Marching:** Camera rays $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ are cast through each image pixel between near ($t_n$) and far ($t_f$) clipping planes.
2. **Stratified Sampling:** 3D coordinates are sampled along each ray.
3. **Harmonic Positional Encoding:** High-frequency sinusoids expand coordinates so the MLP can capture high-frequency geometric details.
4. **Volume Rendering:** Classic numerical quadrature integrates color and density along the ray into a single pixel color:
   $$\hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \left(1 - \exp(-\sigma_i \delta_i)\right) \mathbf{c}_i, \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$$

Because the model learns a smooth, continuous implicit representation of the underlying 3D scene, it can generate realistic views from camera angles never seen during training.

## Getting Started

### 1. Prerequisites
- **Python:** 3.11+
- **GPU:** NVIDIA GPU with CUDA recommended (~4GB VRAM, e.g., RTX 3050)
- **Node.js:** 18+ & npm (for frontend development)

### 2. Environment Setup

```bash
# Clone the repository
git clone https://github.com/mafaqbhatti/nerf.git
cd nerf

# Create and activate virtual environment
python -m venv .venv

# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

## Training & Running the NeRF Model

Navigate to `Model/`:

```bash
cd Model

# 1. Train on real turntable images
python NeRF.py --data_dir "./data" --render_gif

# 2. Quick sanity-check on synthetic procedural sphere (no images needed)
python NeRF.py --synthetic --render_gif
```

### CLI Parameters
| Flag | Default | Description |
|---|---|---|
| `--data_dir` | `None` | Path to sequential images (`001.jpeg`, `002.jpeg`, etc.) |
| `--synthetic` | `False` | Run procedural sphere benchmark |
| `--image_size` | `300` | Input square resolution (pixels) |
| `--num_iters` | `30000` | Training gradient steps |
| `--batch_size` | `2048` | Rays per gradient batch |
| `--hidden_dim` | `256` | MLP hidden layer dimension |
| `--radius` | `4.0` | Camera distance from coordinate origin |
| `--elevation` | `30.0` | Camera elevation angle (degrees) |
| `--render_gif` | `False` | Render 360° rotation GIF upon completion |

**Outputs generated in `Model/`:**
- `training_samples.png`: Preprocessed input images
- `training_loss.png`: MSE loss convergence curve
- `comparison.png`: Ground truth vs rendered views
- `novel_views.png`: Synthesized angles never seen during training
- `360_view.gif`: 60-frame orbiting animation
- `nerf_model.pth`: Serialized model weights

## Running the Web Application

The web app allows users to launch rendering jobs through an interactive web interface.

### Running Backend (FastAPI)
```bash
cd "Web App/backend"

# Optional: configure PostgreSQL by copying .env.example
# cp .env.example .env
# By default, zero-config SQLite (nerf_app.db) is used automatically.

uvicorn main:app --reload --host 127.0.0.1 --port 8000
```
- Open `http://127.0.0.1:8000` in your browser.
- Interactive API documentation: `http://127.0.0.1:8000/docs`.

### Running Frontend in Dev Mode (Optional)
```bash
cd "Web App/frontend"
npm install
npm run dev
```

### Building Frontend for Production
To recompile the UI and serve directly through FastAPI:
```bash
cd "Web App/frontend"
npm run build

# Copy build to backend static folder:
# Windows PowerShell:
Copy-Item -Recurse -Force dist\* ..\backend\static\
```
